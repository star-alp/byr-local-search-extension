# 邮人全搜

邮人全搜是一个非官方的北邮人论坛浏览器扩展。它把论坛的主题、正文和回帖整理成可搜索结果，并支持本地索引、在线读取和本地 Agent 协助。

## 30 秒开始使用

1. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
2. 打开扩展的“邮人全搜”页面，点击“登录论坛”，在同一个浏览器用户配置中登录北邮人论坛。
3. 回到扩展，点击左侧“从论坛读取/刷新版面”，选择需要搜索的版面。
4. 在顶部输入关键词，选择“在线搜索”并点击“搜索”。结果会边读取边出现。

首次打开时可以按页面上的“三步开始搜索”向导操作。已经使用过扩展的用户不会反复看到向导。

## 三种搜索方式

- **在线搜索**：向论坛请求搜索结果，并按需要读取主题正文和回帖。新读取的内容会自动去重写入当前浏览器的本地索引。
- **本地索引**：只搜索当前浏览器已经保存的内容，不访问论坛，适合快速重复查询，也适合多个 AI 或 CLI 同时查询。
- **自动（由 Agent 使用）**：先查询本地索引；如果结果不足，Agent 可以再决定是否执行在线搜索。它不会在没有必要时重复扫描论坛。

本地索引只属于当前浏览器用户配置。切换 Chrome 用户配置后，索引也会随之切换。

## 选择范围和读取量

左侧可以选择版面、每个版面读取多少主题页、每个主题读取多少内容页，以及日期范围。常用组合可以保存为多个范围，之后直接切换。

如果只想补充新增内容，可以在“本地索引管理”中使用增量更新。任务进度会自动保存，浏览器刷新后可以继续查看或继续任务。

## 让本地 AI 帮忙搜索

在扩展中点击“AI 协助”，再点击“复制给 AI”，把提示词粘贴给支持终端的本地 AI（例如 Codex、Claude Code、Trae 或 WorkBuddy）。AI 会按提示自动安装或进入 Bridge 目录、连接扩展并执行搜索。

Bridge/CLI 的公开仓库：<https://github.com/star-alp/byr-local-search-bridge>

AI 连接成功后，直接说“搜索某个关键词”即可。推荐由 AI 执行：

```bash
node agent-cli.mjs ask --query "关键词" --mode auto --scope last-used --limit 20 --pretty
```

需要强制只查本地索引时使用 `--mode local`；需要从论坛重新读取时使用 `--mode online`。

## 隐私和数据

- 扩展不保存论坛密码或 Cookie，也不会把它们发送给 Bridge。
- 论坛请求仍由浏览器当前登录状态完成。
- 本地索引、搜索历史和保存范围保存在当前浏览器的扩展存储中。
- Bridge 只监听本机 `127.0.0.1`，不接收完整网页正文；Agent 只得到搜索结果摘要和原文链接。
- “更多设置”中的“本地索引与隐私”可以查看说明并清空本地索引。

## 常见问题

### 页面显示未连接或版面列表为空

先确认当前 Chrome 用户配置已经登录论坛，再点击“从论坛读取/刷新版面”。如果论坛登录已过期，打开“登录论坛”重新登录后再刷新。

### AI 说无法连接扩展

让 AI 先执行 `node agent-cli.mjs setup --url "扩展 Agent 页面地址"`，再执行 `node agent-cli.mjs doctor`。如果诊断提示扩展未连接，请在安装扩展的同一个 Chrome 用户配置中打开 setup 自动打开的页面。

### 搜索结果很少

在线搜索只会读取当前选择的版面和设置的页数。可以增加版面主题页数、主题内容页数，或扩大日期范围，然后再次更新索引。

### 需要查看当前占用资源

点击“更多设置”，展开“插件资源”，即可查看索引条数、估算大小、浏览器存储、页面内存和本轮请求数量。
